# Raphbee Portfolio

A premium personal portfolio for Raphbee — focused on e-commerce, web development, business automation, and practical AI integrations.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React
- ESLint
- Sharp for portrait optimization

## Local setup

Requirements: Node.js 20.9+ and npm.

```bash
npm install
npm run assets:optimize
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run typecheck
npm run lint
npm run build
```

The GitHub Actions workflow runs the same checks on pushes to `main` and generates optimized WebP portrait assets from the preserved source files.

## Asset policy

The original uploaded assets are preserved at the repository root. The three source portraits are not overwritten. The optimization script generates WebP copies under `public/images/portraits/`.

Current source assets:

- `Raphbee_logo_black_version.png`
- `logo.png`
- `logo_white.png`
- `profile_main.jfif`
- `secondary_profile_image.jfif`
- `complementary_profile_headshot.jfif`

The current Hero uses `profile_main.jfif` while the optimized local WebP assets are generated by CI. Final portrait selection and logo placement remain review items until the visual asset review is confirmed.

## Contact configuration

Contact destinations are intentionally not invented. Add real details in `src/data/site.ts` when ready. No secrets or API keys belong in source control.

## Scope of the current build

The current iteration intentionally contains only the project foundation, Hero, and KPI strip. Additional homepage sections will be added after visual review.
